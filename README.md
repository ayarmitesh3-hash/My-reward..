# My Reward (Test Mode)

My Reward is a test rewards app.

## Features
- User registration and login
- Email verification
- Test coins
- Daily quiz
- Tasks
- Redeem codes
- Admin panel
- Transaction history

## Coin System
100 test coins = ₹1 (display value only).

## Important
- Coins have no real money value.
- No real payments or withdrawals.
- No advertisements.
- Do not reward ad clicks, app reviews or ratings.
- This project is for testing only.
